Use when an owner asks for safe local operational support without publishing side effects.

Focus on status truth, authority boundaries, and specialist routing decisions.

Protect privacy by avoiding credential paths, secret tokens, and unauthenticated profile claims.

Keep authentication guidance minimal and only where owner approval has already been captured.

Maintain durable knowledge through careful handoff summaries with access revocation expectations.

If production, account, payment, external publishing, or destructive action is requested, route through explicit owner approval and preserve setup-access revocation conditions.
