## What the setup agent handles

The owner does **not** complete a technical questionnaire. The setup agent:

- applies the package’s universal mission, safety and approval defaults;
- discovers and verifies timezone, platforms, paths, accounts, storage and installed-version details;
- uses fixed specialist names and profile slugs;
- generates task, board, run, timing and other runtime identifiers when needed;
- marks unavailable technical facts as `Not yet configured — setup agent must discover and verify` rather than guessing;
- generates the private `SOUL.md`, `USER.md`, `MEMORY.md`, `PRIVATE-AGENT-BIBLE.md` and `BOOTSTRAP-PROMPT.md` for owner review.
