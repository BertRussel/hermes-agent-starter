# Agent Bible

Candidate operational manual for a generic owner-operated Hermes system. Not a public release, accepted installation or substitute for native skills/owner authority. The earlier full-system guide is preserved checkpoint reference; this is the canonical generic chapter entry point. Load the relevant chapter/installed skill when needed, not the whole manual into Soul.

Public reusable source and private identity/knowledge/credentials are separate. Native Hermes is the single task/authentication/profile/memory/dispatch authority. Source rights, compatible public runtime acquisition, guarded identity seeds, clean-export onboarding and live owner tests remain required gates. A static coverage PASS cannot satisfy them.
