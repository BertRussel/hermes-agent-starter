# 24. Developer and maintainer guide

## Actor and authority
Maintainers propose source/dependency changes; independent reviewers accept exact bytes. The owner controls main/default branch, public publication and production activation.

## Prerequisites and version
Clean feature workspace, exact base/origin, positive path/command bounds, supported Python/test tooling, provenance and privacy inventory. Never inherit old PASS receipts for recovered or transported source.

## Inputs
Change objective, causal tests, component license/source disposition, compatibility impact and release acceptance matrix.

## Procedure
Read definitions/usages/manifests before edits. Keep one canonical profile distribution and tested native mapping. Write one RED→GREEN behavior slice at a time; run `python3 -B -m pytest -q -p no:cacheprovider` for source regression, then canonical extracted-byte acceptance. Inspect ordinary and untracked changes, dependency/license notices and generated output boundaries. Rebuild clean environments instead of vendoring a live venv. Freeze actual source/head/tree and require independent exact-head review. Prepare public export from accepted positive-allowlisted bytes into fresh public-only history; private factory scripts, paths, receipts, jobs, overlays and prior Git history are not export sources. Scan every exported blob and nested archive, then rerun acceptance from the export. Publish only through the foreground owner-approved exact-byte route, never an implementer's local-only card.

## Expected results
A versioned release has compatible dependency/source pins, truthful notices, sanitized docs, deterministic installable assets and remote readback. Repo creation or a test-only CI result is not release completion.

## Independent verification
Re-download remote assets into a clean environment, compare exact accepted bytes and repeat START-HERE. Check CI belongs to the actual head and no private factory source is required.

## Failure and recovery
Unknown rights/disposition blocks export; replace optional nonredistributable components through a proven legal route without silently removing required capability. Human-controlled main remains a specific owner gate.

## Privacy and outputs
Keep private evidence outside public history and assets; retain security reports through the private owner-approved route.
