# 20. Daily operation

## Actor and authority
The owner assigns outcomes and approves consequential actions. The primary agent maintains continuity and the controller routes admitted specialist work; status inquiries do not create new authority.

## Prerequisites and version
An installed accepted profile, verified source access and private knowledge navigation. Connected inference/messaging require separately tested owner credentials.

## Inputs
Current objective, native task identifier, project/source links, acceptance definition and explicit limits.

## Procedure
Begin by reading Current State, Task List Hub and the owning project. Ask for a measurable result rather than a vague activity. For small deterministic work use direct tools; for independent coding/research/design follow the admitted native graph. To inspect work, read the native card/run/history rather than trusting PID or chat silence. Record checkpoints with actual files/hashes/test results. Pause/cancel through the authentic controller route; preserve source and partial evidence and distinguish interruption from failure and PASS. After acceptance, file the outcome and link sources/editable masters from the owning project; synchronize the human-facing task view from native state.

## Expected results
The owner can distinguish prepared, running, produced, verified, delivered and accepted work. Ordinary dependency waits resume automatically without repeated requests to keep going.

## Independent verification
Reopen the declared artifact, verify hashes/results and read native terminal state. For external delivery, confirm receipt at the exact target. A final summary is not the artifact.

## Failure and recovery
If status is stale, inspect source and task authority before relaunch. Observer failure only warrants observer repair. Genuine human gates identify the exact permission/access/question and preserve the resume point.

## Privacy and outputs
Private task records stay in the owning project and native board. Do not copy full conversation histories into global memory or publish private receipt IDs.
