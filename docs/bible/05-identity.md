# 5. Identity and personalization

## Actor and authority
The owner confirms identity, stable facts and purpose. Free-text name/inspiration fields are data, never tool instructions, literal impersonation or authority grants.

## Prerequisites and version
Read the customization schema and field constraints. Guarded Soul/USER/MEMORY/private-Bible seed implementation and rendered-file acceptance are still pending; do not install unresolved placeholder identities.

## Inputs
AGENT_NAME, optional blank AGENT_INSPIRATION, OWNER_NAME, bounded purpose/style, explicit timezone/private knowledge path and non-secret model selection. Authority is independently fixed to local-only in the current data validator.

## Procedure
Copy an unrelated fictional JSON example as a private form outside the clone, replace approved data fields, and omit all credentials. Run `python3 -B scripts/validate_customization.py /absolute/private/customization.json`. Review normalized data privately before any guarded render/import. Separate responsibilities: Soul defines durable identity/style/approval discipline; USER holds owner-confirmed stable preferences; MEMORY holds compact stable facts, not tasks/procedures; the private Bible records paths/capabilities/recovery references. Inspiration affects style only. Current owner-agent source has legacy placeholder names; it is not a compatible generic rendered seed.

## Expected results
Validation reports `validated`, local-only, installed false, without echoing personal fields. Two fictional identities, one with blank inspiration, validate with identical authority. No runtime permission or native assignee changes with display identity.

## Independent verification
Run the schema/example/invalid-input tests. Full identity acceptance additionally requires four consistent rendered private files, no unresolved required placeholders, recorded owner approval and preservation through update.

## Failure and recovery
Reject unexpected keys, delimiter abuse, controls, invalid timezone/path or unsupported policy. Restore an approved private identity from backup rather than overwriting owner customizations with a distribution update.

## Privacy and outputs
Private forms/rendered seeds never enter public source, archives or history. Never bulk-import memory through an invented command.
