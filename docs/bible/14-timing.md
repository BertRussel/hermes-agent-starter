# 14. Timing and evidence

## Actor and authority
The controller registers the installed timing adapter and records transitions. Timing observes the native lifecycle; it does not schedule, claim, release or decide work.

## Prerequisites and version
The exact supported adapter, telemetry schema and stateless Git-evidence executable must be installed and legally distributable. Public source rights and portable acquisition remain pending for these custom components.

## Inputs
Stable run/project ID, truthful source/workspace binding, phase class, planned estimates, acceptance evidence and native task/session identities.

## Procedure
Preflight the actual adapter help. Start and read back timing before autonomous release. Transition phases against immutable files/committed objects; mutable script hashes cannot be retrospective authority. Record discovery, implementation, verification, independent review, remediation and release preparation separately. Report preparation, launch, artifact creation, acceptance and delivery as distinct events. Derive head/tree from Git rather than an invented target. For stateless native evidence map canonical_repo→expected-repo, origin_remote→expected-remote, actual expected_head→expected-head, parent→expected-parent and repeat each separately quoted allowed-path before native mode. Never export/reconstruct workspace identity. Audit actual delegate_task invocations and matching async delegations, including zero; count leaves separately from invocations.

## Expected results
Every phase has real registered boundaries and immutable evidence. Elapsed blocked intervals are not automatically productive time. Terminal finish or abort reflects the real outcome.

## Independent verification
Read the installed report and task/session records independently. Confirm exact source bindings and validator output, with allowed-path evidence. Missing intervals remain honest gaps, not synthesized estimates.

## Failure and recovery
If timing start/readback fails, keep work blocked. Correct mutable-artifact bindings before release; do not rewrite historical receipts or relabel a failed timing run as accepted.

## Privacy and outputs
Private session/task evidence never ships in public history. Publish sanitized duration summaries only after review.
