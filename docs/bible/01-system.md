# 1. What this system is

## Actor and authority
The owner selects outcomes and grants authority. The owner-facing agent coordinates. Implementer produces candidate code; verifier and reviewer independently evaluate immutable bytes. Researcher and designer supply bounded artifacts, not final acceptance.

## Prerequisites and version
This is a candidate operating manual, not a released product. Native profile packaging was exercised on Linux ARM64, Python 3.11. A compatible custom Hermes revision is required for governed admission; stock upstream installation alone is not evidence of that compatibility.

## Inputs
A reviewed release inventory, source/license notices, owner outcome and private authority policy. Reject a package whose necessary runtime provenance is unknown.

## Procedure
Separate four layers: public reusable source → native runtime/profile distributions → private identity/knowledge/credentials → authorized operational work. Keep native Hermes as task, authentication, profile, memory and dispatch authority. Knowledge notes are navigation, timing is evidence, and archive manifests are integrity records; none is a second dispatcher. Read capability status before installing optional environments.

## Expected results
Every capability has an explicit prepared, tested, installed, connected and accepted state. A folder or passing unit test never implies a connected service or working model.

## Independent verification
Compare inventory with exact archive members and source hashes. A different owner should be able to discover requirements without private machine paths or channel history. Run the released payload's tests independently after extraction.

## Failure and recovery
Missing licenses, unsupported runtime APIs, stale reviews or unknown source hashes block that capability. Preserve candidate evidence and correct the narrow gate; do not weaken acceptance or silently omit a required role.

## Privacy and outputs
Public source contains no live homes, credentials, sessions or private receipts. Personalized outputs and operational evidence remain outside the clone.
