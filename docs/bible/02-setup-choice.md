# 2. Choose your setup

## Actor and authority
The owner chooses hardware, providers, access and cost ceilings. The agent can compare options but cannot purchase infrastructure or create accounts through inferred consent.

## Prerequisites and version
Linux is the tested create-once vault platform. Source tests exercised ARM64/Python 3.11; no claim covers Windows promotion, macOS SDKs or every GPU/browser backend. Profiles isolate configuration, not operating-system permissions.

## Inputs
Expected workload, concurrency, memory/storage budget, external integrations and the capabilities actually required. Separate a personal assistant workload from large inference, browser or media jobs.

## Procedure
Start with one owner-facing profile. Add specialists only for work that benefits from their independent role contract. Use the six public role names through the explicit native mapping; avoid duplicate distributions under cosmetic aliases. Measure idle runtime and one representative bounded task before setting concurrency. Reserve storage for virtual environments, artifact retention and a restore drill; do not choose minimum disk from source archive size alone. Keep the knowledge vault optional and preserve any existing equivalent structure.

## Expected results
A written setup decision states supported architecture, Python/runtime revision, chosen roles, optional dependencies, resource limits and unavailable routes. No implicit production access or inherited jobs are enabled.

## Independent verification
Run dependency consistency and harmless local canaries in the intended environment. Verify cost settings and model availability with owner-supplied credentials separately; offline packaging cannot prove inference.

## Failure and recovery
Resource exhaustion requires lower concurrency or workload-specific sizing, not a new dispatcher. An unavailable browser does not invalidate a tested document route; record the capability-specific failure and documented alternatives.

## Privacy and outputs
Store the decision and measurements in the owning private project. Never publish account IDs or live configuration dumps.
