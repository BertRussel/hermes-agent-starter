## Dependency and architecture contract

Direct upstream dependency/build requirements remain in the selected source
metadata. Canonical proof records the actual resolved host dependency sets;
editable source locators are not placed in recipient lock files. Supporting
requirements are pinned from an actual isolated rebuild. No global install or
system binary is bundled as a hidden prerequisite. Inkscape is an explicit
external prerequisite, with the invoked render version recorded by the adapter.

ARM64/Linux/Python 3.11 was exercised. Other target architectures require a fresh
rebuild and the same positive canaries. A pip check is dependency consistency,
not security review or complete runtime acceptance. An offline wheel cache,
complete hash-locked cross-platform transitive closure and browser/media target
prerequisites are NOT yet demonstrated.
