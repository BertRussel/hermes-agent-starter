# Decision Journal Index

No real owner decision is asserted by this starter. Index accepted durable decisions here and link the owning project. Draft hypotheses and raw sources are not policy.

Each record needs question, chosen option, reasons/tradeoffs, authority/approver, date, consequences, evidence and reversal conditions. A newer note supersedes an older decision only when that relationship is explicit. Preserve historical provenance behind an archive/superseded boundary.
