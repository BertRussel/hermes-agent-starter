# Native pipeline runbook

1. The owner gives direction to Primary. Primary creates one blocked durable root.
2. Record and read back the exact `notify+wake` route and timing run before release.
3. Root alone creates blocked children, links all dependencies, admits each child, then releases it through the Gateway dispatcher. No wrappers, tmux, cron, direct named-profile starts, or generic delegate impersonation are permitted.
4. Forge works in its isolated worktree, tests, commits, validates the exact head, and freezes bytes.
5. Primary/controller independently verifies the frozen exact head; Bert-Verifier then reviews it. Eve is admitted only after Bert-Verifier and reviews the same bytes.
6. A substantive finding may create one bounded remediation generation. Park the root while dependencies run; resume only through the dependency graph.
7. Close timing only after final verdict, owner decision, evidence retention, and a terminal closeout. Keep credentials and private runtime data outside task records.
